# SQLAlchemy & Alembic Guidelines

## Version Check Requirement
Check `sqlalchemy` and `alembic` versions in package manifests:
- SQLAlchemy 2.0 uses `mapped_column()` and `Mapped[]` type hints.

## Alembic Migration Rules
- Generate migrations: `alembic revision --autogenerate -m "description"`.
- Verify autogenerated migration script for correctness before running `alembic upgrade head`.
- Ensure `upgrade()` and `downgrade()` methods are both defined.
