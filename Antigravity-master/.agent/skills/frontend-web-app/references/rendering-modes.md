# Rendering Modes & Strategies

## Strategies Summary
- **SSR (Server-Side Rendering)**: Render dynamic HTML per request for personalized data.
- **SSG (Static Site Generation)**: Build static HTML at build time for fast delivery.
- **ISR (Incremental Static Regeneration)**: Re-render static pages in the background after specified revalidation intervals.
- **Hydration Safety**: Ensure initial server HTML matches client render HTML to prevent hydration errors.
