# Color System & Design Tokens

## Semantic Token Roles
- `color-primary`: Brand identity and call-to-action elements.
- `color-neutral`: Text, borders, backgrounds.
- `color-success`, `color-warning`, `color-error`: Feedback states.
- `color-surface`: Card, modal, and overlay backgrounds.

## WCAG AA Contrast Requirements
- Normal text (below 18pt): minimum contrast ratio 4.5:1.
- Large text (18pt+ or bold 14pt+): minimum contrast ratio 3:1.
- UI components and focus indicators: minimum contrast ratio 3:1.
