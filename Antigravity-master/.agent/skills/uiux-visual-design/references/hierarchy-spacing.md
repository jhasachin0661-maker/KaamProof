# Visual Hierarchy & Spacing Guidelines

## Spatial Grid System
- Use an 8pt base grid: all padding, margin, gap, and sizing values should be multiples of 4 or 8 (4, 8, 12, 16, 24, 32, 48, 64).
- Maintain consistent vertical rhythm between sections.
- Align content to a 12-column or 16-column responsive grid layout.
