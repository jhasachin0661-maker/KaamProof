# Vetted Authentication Providers

## Provider Mappings
- **Auth.js (NextAuth.js)**: Ideal for Next.js and Node web apps. Supports JWT and database session strategies.
- **Clerk**: Turnkey identity management for user management, MFA, and organization RBAC.
- **Supabase Auth**: Integrated PostgreSQL Row Level Security (RLS) identity solution.
- **Firebase Auth**: Managed authentication for web, iOS, and Android applications.
