# MVP Scoping Guidelines

## Core Principles
1. **Solve One Core Problem Exceedingly Well**: Avoid horizontal feature breadth. Focus on a single vertical user journey.
2. **Cut Scope, Not Quality**: Deliver a polished, bug-free slice rather than a bloated, half-baked application.
3. **Defer Non-Essential Automation**: Manual back-office processes ("Wizard of Oz" pattern) are acceptable for early MVPs.
