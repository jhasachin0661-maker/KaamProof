# Feature Prioritization Frameworks

## 1. RICE Framework
Scoring formula: `RICE Score = (Reach * Impact * Confidence) / Effort`

- **Reach**: Number of users impacted per time period (e.g. 1,000 users/month).
- **Impact**: Score from 0.25 (minimal) to 3.0 (massive). (3 = massive, 2 = high, 1 = medium, 0.5 = low, 0.25 = minimal).
- **Confidence**: Percentage percentage of certainty (100% = high data confidence, 80% = medium, 50% = low).
- **Effort**: Estimate in person-months or story points.

## 2. MoSCoW Framework
- **Must-Have**: Non-negotiable core features. Without these, the product cannot launch.
- **Should-Have**: Important features that add significant value but are not critical for launch.
- **Could-Have**: Desirable features ("nice-to-haves") implemented if time/budget permits.
- **Won't-Have (this time)**: Features explicitly out of scope for the current release.
