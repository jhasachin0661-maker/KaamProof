# Code Review Checklist

## Review Areas
- **Correctness & Logic**: Verify boundary conditions, null/undefined checks, and exception safety.
- **Contract & API Safety**: Check function signatures, return types, and interface contracts.
- **Resource Management**: Verify open file handles, database connections, and event listeners are cleaned up.
- **Performance & Scalability**: Audit query loops, redundant compute, and memory allocations.
- **Test Coverage**: Ensure new or modified logic paths are accompanied by unit or integration tests.
