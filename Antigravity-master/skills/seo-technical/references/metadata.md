# Page Metadata Rules

## Required Tags (Every Page)
```html
<html lang="en">
<head>
  <!-- Unique per page; 50-60 chars -->
  <title>Product Dashboard | MyApp</title>

  <!-- Unique per page; 120-160 chars -->
  <meta name="description" content="Manage all your projects from one place with the MyApp dashboard.">

  <!-- Self-referencing canonical to prevent duplicate content -->
  <link rel="canonical" href="https://myapp.com/dashboard">
</head>
```

## Rules
- `<title>`: 50–60 characters. Include primary keyword and brand name.
- `<meta name="description">`: 120–160 characters. Describe page content accurately.
- One `<h1>` per page. Heading hierarchy (`h1 > h2 > h3`) must be sequential.
- `lang` attribute on `<html>` tag is required.
