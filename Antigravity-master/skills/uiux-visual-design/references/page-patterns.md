# Page Layout Patterns

## Dashboard Layout
- Left sidebar navigation (240px fixed) + main content area with breadcrumb header.
- Data-heavy panels use card grids (2-4 column responsive).

## SaaS Application Layout
- Top navigation bar + sidebar + content well with settings panel.

## Landing Page Layout
- Hero section -> Feature highlights -> Testimonials -> Pricing -> Call-to-Action footer.

## Mobile View
- Bottom tab navigation or hamburger drawer overlay. Full-width cards and single-column layout stacks.
