# Typography System Guidelines

## Type Scale & Hierarchy
- Use a modular type scale (1.25x or 1.333x ratio): xs, sm, base, lg, xl, 2xl, 3xl, 4xl.
- Heading weight: 600-700. Body weight: 400. Label weight: 500.
- Body line-height: 1.5-1.6. Heading line-height: 1.1-1.25.
- Prefer system font stacks or Google Fonts (Inter, Geist, Outfit) over browser defaults.
