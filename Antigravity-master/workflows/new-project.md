# Workflow: New Project

**Instruction to Agent:** Adopt the `dev-orchestrator` skill and execute the following plan template to set up a new project.

## Plan Template

1. **requirements**: Define and gather project requirements (`core-requirements-planning`).
2. **architecture**: Establish the initial architecture and system design (`arch-system-design`).
3. **scaffold**: Scaffold the project structure and initial boilerplate code.
4. **baseline CI**: Set up baseline Continuous Integration pipelines (`devops-ci-cd`).
5. **docs**: Create foundational documentation (README, setup guide, architecture docs).
6. **gate**: Pass the quality release gate (`quality-release-gate`) before concluding setup.
